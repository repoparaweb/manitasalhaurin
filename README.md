# Web Manitas

Landing estatica para una persona que ofrece servicios de manitas, reparaciones y mantenimiento.

## Archivos

- `index.html`: estructura y textos.
- `assets/styles.css`: estilos responsive.
- `assets/script.js`: menu movil y formulario que abre WhatsApp.
- `assets/images/`: carpeta preparada para fotos reales de trabajos.

## Contacto configurado

WhatsApp y telefono: `602 53 75 09`

## Como verla

Abre `index.html` en el navegador o usa Live Server en Visual Studio Code.

## Antes de publicar

Edita:

- Nombre comercial o nombre de la persona.
- Zona real de trabajo.
- Fotos reales de antes/despues.
- Opiniones reales de clientes.
